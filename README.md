# agents

Marketplace repository for AI agent integrations so Claude Code, ChatGPT Codex, and similar agents can install connectors/skills/plugins/MCP servers to operate [RAVE](https://rave.wiki).

## Included integrations

- [dipterix/shidashi](https://github.com/dipterix/shidashi): shidashi MCP server and RAVE skill.
- [rave-ieeg/rave-pipelines](https://github.com/rave-ieeg/rave-pipelines): RAVE agents/skills.
- `inst/three-brain-hub`: in-progress MCP server tools for [dipterix/threeBrain](https://github.com/dipterix/threeBrain).
